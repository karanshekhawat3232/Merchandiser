FILE: routes/index.js  (mounted at "/" in app.js)
--------------------------------------------------------------

[MODIFIED] GET /addtocart/:productid  — protected by isLoggedin
  - Full try/catch wrapping every async operation
  - Validates product exists BEFORE pushing — flashes "Product not found" + redirects /shop if missing
  - Finds user by req.user.email, pushes productid onto user.cart, saves
  - On success: req.flash("success", "Item added to cart") + redirect /shop
  - On any error: req.flash("error", "Could not add item to cart") + redirect /shop

[MODIFIED] GET /cart  — protected by isLoggedin
  - Full try/catch
  - Fetches user + .populate("cart") in a single query
  - Guards against null user (flashes error, redirects)
  - Empty cart guard: if cart.length === 0, renders cart.ejs with bill = { totalMRP:0, totalDiscount:0, platformFee:20, totalAmount:20 } — no division/reduce on empty arrays
  - Grouping logic: iterates populated cart items, groups by _id.toString() to count duplicate ObjectId entries as quantity
  - Bill computation:
      • totalMRP      = sum(price * quantity) per grouped product
      • totalDiscount = sum(discount * quantity) per grouped product  [discount is a flat ₹ amount]
      • platformFee   = 20 (fixed constant)
      • totalAmount   = totalMRP - totalDiscount + platformFee
  - Passes bill = { totalMRP, totalDiscount, platformFee, totalAmount } object to view (not a scalar)

[NEW] GET /account  — protected by isLoggedin
  - Full try/catch
  - Fetches full user document by req.user.email (purchaseHistory is embedded, no populate needed)
  - Sorts purchaseHistory descending by orderDate server-side using .slice().sort() — does NOT mutate the original array with .reverse()
  - Renders account.ejs with { user, purchaseHistory: sortedHistory }

ROUTING SUMMARY (how URLs map to files)
--------------------------------------------------------------

  GET /             → routes/index.js → views/index.ejs
  GET /shop         → routes/index.js (isLoggedin) → views/shop.ejs
  GET /addtocart/:id→ routes/index.js (isLoggedin) → redirect /shop
  GET /cart         → routes/index.js (isLoggedin) → views/cart.ejs
  GET /account      → routes/index.js (isLoggedin) → views/account.ejs

  POST /user/register → routes/userRouter.js → controllers/authController.js
  POST /user/login    → routes/userRouter.js → controllers/authController.js
  GET  /user/logout   → routes/userRouter.js → controllers/authController.js

  Middleware:  middelwares/isLoggedin.js
               → reads JWT from cookie → verifies → sets req.user → calls next()
               → on failure: req.flash("error","You Need To Login First") + redirect /
